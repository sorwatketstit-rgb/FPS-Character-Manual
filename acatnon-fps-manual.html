Visual System

1. Base FPS Character

รากฐานของตัวละครมุมมองบุคคลที่หนึ่ง มีสคริปต์อยู่ที่ Assets/Codes/Base/

Prefabs

  • Player.prefab พร้อมใช้งาน

Materials

  • Player, Ground, Enemy

Preview

  • Preview Scene.unity ซีนทดสอบ

SimpleFPSCamera.cs

ควบคุมมุมกล้องด้วยเมาส์ และล็อกเคอร์เซอร์อัตโนมัติเมื่อเริ่มเกม

  • เมาส์แกน X หมุนตัวละคร (Yaw) แกน Y หมุนเฉพาะ cameraHolder (Pitch)
  • จำกัดองศาก้มเงยด้วย maxLookAngle
  • ปรับ mouseSensitivity และกลับแกนด้วย invertY

SimpleMovement.cs

เดิน วิ่ง กระโดด ด้วยแรง AddForce(..., ForceMode.VelocityChange) ใน FixedUpdate

  • ตรวจพื้นด้วย Raycast ลงไปที่ Layer groundMask
  • gravityMultiplier เพิ่มแรงโน้มถ่วงตอนตก ให้การกระโดดกระชับ
  • สลับแรงต้านอัตโนมัติ: บนพื้นใช้ groundDrag อากาศใช้ airDrag และ airControl

SimpleShooting.cs

ยิง Hitscan ด้วยคลิกซ้าย (Fire1) โดยยิง Raycast จากกลางหน้าจอไปยัง Layer ใน hitLayers

2. Movement Expansion

การเคลื่อนไหวลื่นไหลสไตล์ Action FPS ประกอบด้วย ExtraMovement.cs, Player.prefab และ Wall.mat

ExtraMovement.cs

Coexistence

ใส่ movementScriptToSuspend เพื่อปิด SimpleMovement ชั่วคราวตอนสไลด์หรือไต่กำแพง ไม่ให้ฟิสิกส์ตีกัน

Double Jump

กระโดดกลางอากาศได้ตาม maxAirJumps รีเซ็ตความเร็วแกน Y ก่อนใส่แรง airJumpForce

Slide

  • กด Left Shift บนพื้น เมื่อเร็วกว่า slideMinSpeed
  • พุ่งด้วย slideBoost ลดแรงเสียดทาน slideDrag
  • ลดความสูง Collider เหลือ slideHeightMultiplier (ปกติ 60%)
  • เพดานเตี้ยจะลุกไม่ได้ (CanStandUp ใช้ SphereCast)
  • เอียงโมเดลด้วย playerModel

Wall Run & Wall Jump

  • ชนกำแพง Layer wallMask ที่ Normal ทำมุม 70°–110°
  • หน่วงการตกด้วย wallRunFallClamp
  • กด Space เพื่อดีดออกจากกำแพง

3. Visual System

เพิ่มความสะใจให้การยิง (Juice / Feedback) สคริปต์หลักคือ GunFeel.cs

Prefabs ที่มีให้

  • Player Variant.prefab ตัวละครติดปืน AK-47 และระบบครบ
  • Ak-47.prefab โมเดลปืนพร้อม Pivot และ MuzzlePoint
  • Muzzle Flash, Bullet Hole, Impact Particle, Crosshair

GunFeel.cs

  • Fire Modes Semi-Auto (คลิกทีละนัด) หรือ Full-Auto (กดค้าง ตาม fireRate)
  • Procedural Recoil ปืนดีดขึ้น (kickAngle) ส่ายซ้ายขวา (horizontalKick) และถอยหลัง (kickBackDistance) คุมความไวด้วย snappiness และการกลับที่ด้วย recoverySpeed
  • Dynamic Audio สุ่ม Pitch ระหว่าง minPitch–maxPitch ทุกนัด
  • Muzzle Flash เกิดที่ muzzlePoint และหายไปตาม muzzleFlashLifetime
  • Decal & Impact รอยกระสุนแนบตาม hit.normal สุ่มมุมหมุน 360° ติดกับวัตถุที่ถูกยิงได้ (parentDecalToHitObject) พร้อมสะเก็ดกระสุนและตัวตั้งเวลาลบ decalLifetime

วิธีติดตั้งและใช้งาน

  1. สร้าง Layers ใน Tags & Layers ของ Inspector
    • Ground พื้นที่เดินได้
    • Enemy เป้าหมาย/ศัตรู
    • Wall กำแพงที่วิ่งเกาะได้ (สำหรับ Movement Expansion)
  2. วาง Prefab ลง Scene

    แบบพื้นฐาน: ลาก BaseFPSCharacter/Assets/Prefabs/Player.prefab ลง Hierarchy แล้วตั้ง SimpleMovement → Ground Mask = Ground และ SimpleShooting → Hit Layers = Enemy (หรือ Default)

    แบบเต็ม: ลาก Visual System/Assets/Prefabs/Player Variant.prefab แล้วตรวจค่าตามนี้

    • SimpleMovement: Ground Mask = Ground
    • ExtraMovement: Ground Mask = Ground, Wall Mask = Wall, Movement Script To Suspend = ลาก SimpleMovement มาใส่, Player Model = โมเดลที่จะเอียง
    • GunFeel (ที่ Gun/Ak-47 หรือ Player): Hit Layers = Ground, Enemy, Default
  3. กด Play ทดสอบได้ที่ Preview Scene.unity
ถ้า Slide หรือ Wall Run แล้วตัวละครรู้สึกหนืด ให้ตรวจว่าใส่ SimpleMovement ใน Movement Script To Suspend แล้ว
